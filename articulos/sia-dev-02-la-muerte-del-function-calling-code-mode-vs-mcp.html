Por qué los LLMs son mediocres invocando herramientas JSON una por una, pero extraordinarios escribiendo código TypeScript en sandboxes V8.

Tesis Central de Investigación

"La transición del paradigma de invocación secuencial de herramientas (JSON Tool Calling) hacia la síntesis programática de código ejecutable en sandboxes ligeros (Code Mode) elimina la inflación de contexto en servidores MCP masivos y reduce el consumo de tokens en un 99.9%."

Nexo de Bitácora: Segundo episodio de sIA Dev: Evolución del protocolo MCP de Anthropic, V8 Isolates de Cloudflare, optimización de ventana de contexto y agentes autónomos.

1. La Crisis de Escalabilidad del Tool Calling Tradicional en MCP

Cargar los esquemas JSON de los 2,500 endpoints de la API de Cloudflare en un servidor MCP tradicional consume 1.17 millones de tokens antes de que el usuario escriba su primera instrucción. Además, los modelos de lenguaje sufren degradación de razonamiento al encadenar decenas de llamadas JSON secuenciales (round-trips).

2. Code Mode y Sandboxes V8 Isolates: De 1.17 Millones a 1,000 Tokens

En lugar de exponer miles de herramientas estáticas, Code Mode entrega al agente únicamente dos funciones: 'search()' y 'execute()'. El LLM consulta la documentación tipada bajo demanda y escribe un script completo en TypeScript que se ejecuta en milisegundos dentro de un Dynamic Worker V8 Isolate sin acceso a internet abierto, abatiendo el costo de contexto en un 99.9%.
